## Setup
1. Open **SSMS** and connect to your SQL Server instance.
2. Open `docs/RaceDay_Database.sql` and click **Execute**. It creates `RaceDayDB`, all tables and the seed data (safe to re-run).

## ERD vs SQL
The SQL script matches the ERD exactly. Design notes:
* `Enrolments` resolves the many-to-many between Users (Participants) and Events and also stores the chosen Category.
* A **composite foreign key** `(CategoryId, EventId)` on `Enrolments` guarantees a participant can only pick a category belonging to the same event.
* `Results` is 1-to-0..1 with `Enrolments` (`EnrolmentId` is UNIQUE).
* Seed `PasswordHash` values are placeholders; real hashes are generated by the API at registration (Part 2).
